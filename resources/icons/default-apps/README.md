# Default application artwork

The 34 branded application SVGs in this directory are unmodified artwork
from **Papirus icon theme**, copyright the Papirus Development Team and
contributors, licensed under **GPL-3.0**. The full license is Trophy's root
`LICENSE`, also embedded alongside this notice and installed with it.

Upstream: https://github.com/PapirusDevelopmentTeam/papirus-icon-theme

Imported from the signed Arch Linux `papirus-icon-theme` package
`20260801-1` (upstream release `20260801`), `Papirus/48x48/apps/`.
Symlinks were dereferenced; file contents were not edited. There is no
runtime or build-time dependency on Papirus or on network access.

GPL-3.0-or-later. They represent unidentified reporters/accessibility helpers
and test cubes respectively; they are not claimed to be vendor logos.

Application names and logos identify the respective products. No trademark
rights or endorsement are implied. Installed desktop/theme icons take
precedence over these bundled fallbacks.
