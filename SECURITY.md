# Security Policy

## Supported Versions

Only the latest stable release of Trophy is actively supported. Users are encouraged to keep their installations up to date.

## Reporting Vulnerabilities

If you discover a security vulnerability in Trophy, please report it privately through [GitHub's private vulnerability reporting system](https://github.com/stevenjwheeler/Trophy/security/advisories/new).

Where possible, please include:

- A description of the vulnerability.
- The affected version.
- Steps to reproduce the issue.
- The potential security impact.

Please allow the maintainers a reasonable opportunity to investigate and address the vulnerability before publicly disclosing it.

## Official Distributions

Users are encouraged to download Trophy through official distribution channels identified by the project maintainers.

Suspected malicious distributions, compromised downloads or websites impersonating Trophy should be reported privately to the maintainers.

Independently maintained forks are not supported or endorsed by the Trophy project unless explicitly stated otherwise.

For further information, please refer to the [Trademark and Attribution Policy](TRADEMARK.md).

## Security Advisories

Where appropriate, confirmed security vulnerabilities and their fixes will be communicated through GitHub Security Advisories or official release announcements.
